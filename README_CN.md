## 关于Infx
这是一个受[MITE](https://avernite.ca/MITE/)启发，并进行现代化修改的mod。可见，这个mod是困难的。  

开发迄今为止，仍然不是这个mod真正的正式版，但它可玩。  

无论是数值不平衡或者机制不合理，它都在可接受范围内。  

如何通关，可以参照1.6.4-MITE的实况视频；关于新内容，你也能在CHANGELOG_CN中查看。
